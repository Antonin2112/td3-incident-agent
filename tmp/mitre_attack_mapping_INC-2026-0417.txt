# MITRE ATT&CK Mapping for Incident INC-2026-0417

## Incident Overview
Two related alerts: (1) SQL injection / data exfiltration on web server `web-01`, (2) PowerShell execution on workstation `PC-COMPTA-07` via malicious email attachment. Both are linked through the same external IP `203.0.113.42` and the domain `malicious-domain.ru`.

## Technique Mapping

### 1. T1059.001 - PowerShell
**Tactic:** Execution  
**Evidence:**
- `edr_events.jsonl` line 2: PowerShell command line `powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\Users\m.durand\AppData\Local\Microsoft\Windows\INetCache\Content.Outlook\X7K2P9QZ\facture_2024-11.ps1` (parent: OUTLOOK.EXE)
- `facture_2024-11.ps1.txt` contains obfuscated PowerShell code with Base64-encoded command, variable splitting, and staged downloads from `http://192.168.1.100/stage1.ps1`, `http://192.168.1.101/beacon.exe`, `http://malicious-domain.ru/payload.dll`

**Validation:** ✅ Valid MITRE ID T1059.001

## Link Between Alerts
The two alerts are **linked** through:
1. Same external attacker IP `203.0.113.42`
2. Same C2 domain `malicious-domain.ru`
3. Same PowerShell payload `facture_2024-11.ps1` delivered via email to `PC-COMPTA-07` and used in web-based SQL injection from `203.0.113.42` against `web-01`
4. Attack chain: Email phishing → PowerShell execution → System discovery & persistence → C2 via HTTP → Data exfiltration
